# Machine Learning for Everyone

A complete book and a free, fully-offline companion app for learning classical machine learning by doing.

**Site:** https://ismaelabdulrahman.github.io/machine-learning-for-everyone/

## What's here

- **`index.html`** — the site (GitHub Pages serves this from the repo root).
- **`book/`** — the book, as a downloadable PDF.
- **`assets/`** — images used by the site (cover, icons, screenshots, social-preview image).

ML Studio, the companion app, lives in its own repo so this one stays focused on the book: [ml-studio-app](https://github.com/IsmaelAbdulrahman/ml-studio-app) — a self-contained web build (HTML/JS + Pyodide, the same code that ships on Android), live at https://ismaelabdulrahman.github.io/ml-studio-app/.

## The book

21 chapters, from "what is machine learning?" through ensembles, kernels, clustering, and two complete case studies, plus two reference appendices on the math and the Python/NumPy/scikit-learn tools used throughout. Every chapter follows the same shape: the idea in plain words, the equations with every symbol explained, a worked example with real numbers, the assumptions, and runnable code.

## The app — ML Studio

Four tabs: **Play** (an interactive model-fitting playground), **Labs** (six focused simulations), **Learn** (the full book on-device), and **Practice** (worked examples and a quiz per chapter). No account, no internet permission, no data collection — everything runs and stays on-device.
